## Decisions Made

1. **Transfer-only optimization** — Eliminates dual variable instability. Much simpler, economically intuitive.
2. **No dual variables in optimization loop** — Compute shadow prices after convergence using marginal utilities.
3. **Remove "Stable/Unstable" indicator** — Unweighted graphs always have ρ ≥ 1 for connected networks, so the indicator was misleading.
4. **HTML5 Canvas for adjacency matrix** — SVG with 2500 rectangles is too slow. Canvas is the right tool.
5. **Inline quick results** — Users want immediate feedback. Mini-charts below network provide this without tab switching.
6. **Teal/cyan color scheme** — Chosen for scientific feel, colorblind accessibility, and distinction from corporate blue.

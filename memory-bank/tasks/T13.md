## Context

Following completion of T1-T12 (econ-sim v1.1 is live), Deepak identified that the graph infrastructure used across multiple projects should be extracted into reusable npm packages. The `spin-network-app` repository contains mature graph packages (`graph-core`, `graph-ui`) that were never published independently. Meanwhile, `econ-sim` has built custom graph and visualization code that duplicates some functionality and adds domain-specific features.

The goal is to create a focused monorepo `space-cadet/graph-tools` containing:
- `@space-cadet/graph-core`: Clean graph theory library
- `@space-cadet/graph-ui`: Multi-renderer visualization layer

### graph-core Features
- Graphology adapter with typed interfaces
- Graph generators: empty, complete, path, random, lattice (1D/2D, periodic)
- Matrix operations: adjacency, Laplacian
- Spectral radius via power iteration (ported from econ-sim)
- BFS pathfinding
- Graph metadata support

### graph-ui Features
- **SigmaRenderer**: 2D graph via Sigma.js (existing)
- **ThreeRenderer**: 3D graph via Three.js (existing)
- **D3Renderer**: 2D force-directed with econ-sim features (NEW)
  - Flow animation particles
  - Interactive edge creation (ghost lines)
  - Drag-and-drop
  - Selection rings
  - Node overlays (dynamic labels)
- LayoutManager with caching
- React GraphCanvas component

## Decisions Log

- **Namespace**: `@space-cadet/*` (user owns npm scope, already publishes `ts-quantum`)
- **Monorepo vs separate repos**: Monorepo (packages tightly coupled, single maintainer)
- **Migration order**: Copy raw first, then clean (leave spin-network-app untouched)
- **Scope**: graph-core + graph-ui only (not quantum, tensor, template packages)

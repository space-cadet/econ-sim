## Problem

The D3 network visualization had multiple issues:
1. Nodes clustered in corner — force simulation didn't use available space
2. Labels invisible — dark text on dark background
3. Clicking restarted simulation — update pattern missing `.merge()`
4. Stocks never updated — `updateStocks()` called but labels showed "0.0"
5. No visual feedback during simulation

## Solution Implemented

### D3 Update Pattern Fix

Fixed proper enter/update/exit pattern with `.merge()`:

```javascript
// BEFORE (broken):
const nodeEnter = node.enter().append("g");
nodeEnter.append("circle");
// Missing: node.merge(nodeEnter) — caused full re-render on every click

// AFTER (fixed):
const nodeEnter = node.enter().append("g");
nodeEnter.append("circle");
nodeEnter.append("text");  // Added visible labels
const nodeUpdate = node.merge(nodeEnter);  // Proper merge
nodeUpdate.select("circle").attr("fill", ...);  // Update existing
```

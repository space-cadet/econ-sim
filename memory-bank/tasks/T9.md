# T9: Fix D3 Visualization & Interaction

## Status: pending
**Priority**: HIGH
**Dependencies**: T7, T8

## Problem

The D3 network visualization has multiple issues that make it frustrating to use:

1. **Nodes cluster in corner** — Force simulation doesn't use available space
2. **Labels invisible** — Dark text on dark background
3. **Clicking restarts simulation** — Update pattern missing `.merge()`
4. **Stocks never update** — `updateStocks()` called but labels show "0.0"
5. **No visual feedback on simulation** — Clicking Run just flashes the canvas

## Details

### D3 Update Pattern (Critical)

Current code in `visualization.js`:

```javascript
const nodeEnter = node.enter().append("g")...;
// Missing: node.merge(nodeEnter) for updates
```

When `update()` is called (e.g., after clicking a node), it rebuilds the entire selection. The force simulation restarts from scratch, causing nodes to jump.

### Label Color

```javascript
nodeEnter.append("text")
  .attr("fill", "#2c3e50")  // Invisible on #0f0f23 background
```

### Stock Labels

The stock text is appended as:
```javascript
nodeEnter.append("text")
  .attr("class", "stock-label")
  .text(d => d.stock?.toFixed(1) || "0");
```

But `updateStocks()` tries to select `.stock-label` from the merged selection, which doesn't exist because the merge was never done.

## Proposed Fix

1. Fix D3 join pattern:
   ```javascript
   const nodeEnter = node.enter().append("g");
   nodeEnter.append("circle");
   nodeEnter.append("text");
   const nodeUpdate = node.merge(nodeEnter);
   nodeUpdate.select("circle").attr("fill", ...);
   ```

2. Fix label colors: use `#eee` or `#fff`

3. Fix stock label selection and update

4. Add flow animation during simulation run

5. Consider pinning default network nodes to reasonable positions instead of pure force layout

## Files to Modify

- `src/visualization.js` — main fix
- `src/ui.js` — add simulation feedback

## Notes

For a demo tool, the network should feel responsive and predictable. The force layout is nice for organic feel, but default scenarios should have stable initial positions.

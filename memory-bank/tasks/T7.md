## Status: 🔄 IN PROGRESS

**Started**: 2026-08-10
**Dependencies**: —

## Problem

The gradient-based solver in `simulation.js` never converges. Shadow prices explode to ~1e16, and the solver hits the 1999-iteration limit on every run.

## Root Causes

1. **Dual update unbounded**: `updateShadowPrices()` adds `alpha * violation` with no normalization
2. **No constraint projection**: Primal variables (consumption, transfers, stocks) not projected onto feasible set
3. **Flow balance never satisfied**: Because primal variables are infeasible, shadow prices grow indefinitely
4. **Convergence check meaningless**: Compares welfare float difference against tol=1e-8, but welfare is dominated by noise from infeasible states

## Proposed Fix

### Option A: Proper Augmented Lagrangian
- Add penalty term to objective: `(ρ/2) * ||constraint violation||²`
- Update multipliers with damping: `λ ← λ + α * violation`, then normalize
- Project primal variables after each step

### Option B: Simplify to Feasible Solver
- Since this is a demo/learning tool, simplify the economic model:
  - Assume stocks are slack (don't optimize over S)
  - Solve consumption via closed-form CRRA + transfer balance
  - Use just flow-balance constraints (easier to project)

### Option C: Use Existing JS Optimization Library
- Consider `optimization-js` or `numeric.js` for constrained optimization
- Would add dependency but get correct behavior

## Problem

The gradient-based solver in `simulation.js` never converged. Shadow prices exploded to ~1e16, and the solver hit the 1999-iteration limit on every run.

## Root Causes

1. **Dual update unbounded**: `updateShadowPrices()` added `alpha * violation` with no normalization
2. **No constraint projection**: Primal variables (consumption, transfers, stocks) not projected onto feasible set
3. **Flow balance never satisfied**: Because primal variables were infeasible, shadow prices grew indefinitely
4. **Convergence check meaningless**: Compared welfare float difference against tol=1e-8, but welfare dominated by noise from infeasible states

## Solution Implemented

### Transfer-Only Feasible Optimization

Instead of full primal-dual gradient descent over all variables, simplified to **transfers as the only decision variables**:

```javascript
// New solver architecture:
// 1. Transfers τ_ij are decision variables
// 2. Consumption computed from flow balance: c_i = ω_i + Σ_j τ_ji - Σ_j τ_ij
// 3. Project c_i ≥ 0, τ_ij ≥ 0
// 4. Producer nodes: constrain total outflows = productivity (simplex projection)
// 5. No dual variables during optimization — compute shadow prices post-hoc
```

### Key Functions Added

- `projectOntoSimplex(v, sum)` — O(n log n) algorithm for simplex projection
- `gradientTransfers(transfers, stocks, t)` — Gradient of Lagrangian w.r.t. transfers
- `solveFeasibleTransfers()` — Main loop with adaptive step size
- `computeFlowsAndStocks(transfers)` — Derive all economic quantities from transfers

## Results

- **Before**: "Not converged after 1999 iter", welfare = -21.66, shadow prices = 3×10¹⁶
- **After**: Converges in ~70 iterations, welfare = 0.3-0.5 per period, reasonable shadow prices

## Files Modified

- `src/simulation.js` — Complete solver rewrite (transfer-only optimization)

## Notes

The new solver is economically intuitive: transfers ARE the choice variables in this model. Everything else (consumption, stocks, shadow prices) follows from the transfer pattern. This is both simpler numerically and conceptually clearer for a physics audience.

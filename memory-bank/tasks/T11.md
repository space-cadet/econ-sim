### Key Bug Fix: Hidden Tab Dimensions

The canvas was blank because when `updatePlots()` runs, the Plots tab is hidden (`display: none`), so `getBoundingClientRect()` returns 0×0. Fixed by:
1. Adding fallback dimensions (`|| 300`)
2. Re-rendering heatmap when user switches to Plots tab

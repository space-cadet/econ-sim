### Adjacency Heatmap

**Current**: Chart.js scatter plot with pointRadius based on value
**Problem**: Looks like scattered dots, not a matrix
**Fix**: Use HTML5 Canvas with manual pixel rendering:

```javascript
// Draw n×n grid
for (let i = 0; i < n; i++) {
  for (let j = 0; j < n; j++) {
    const val = A[i][j];
    ctx.fillStyle = val > 0 ? `rgba(45, 212, 191, ${val})` : 'transparent';
    ctx.fillRect(j * cellW, i * cellH, cellW, cellH);
  }
}
```

Or use a simple HTML table with colored cells.

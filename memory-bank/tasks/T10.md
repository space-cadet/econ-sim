## Problem

Current color scheme used `#e74c3c` (bright orange-red) as primary on `#1a1a2e` (dark blue-black). User feedback: "Orange over dark looks very weird."

## Issues

1. Orange-red on dark was harsh and drew too much attention
2. Looked like an error/warning color, not a primary brand color
3. Lacked sophistication for an academic/research tool
4. Poor accessibility — red-green colorblind users couldn't distinguish producer/household nodes

## Solution Implemented

### Teal/Cyan on Slate (Option A)

```css
:root {
  --bg-page: #0f172a;       /* slate-900 */
  --bg-panel: #1e293b;      /* slate-800 */
  --bg-canvas: #020617;     /* slate-950 */
  --text-primary: #e2e8f0;  /* slate-200 */
  --text-secondary: #94a3b8;/* slate-400 */
  --text-muted: #64748b;    /* slate-500 */
  --accent-primary: #2dd4bf;/* teal-400 */
  --accent-secondary: #60a5fa; /* blue-400 */
  --accent-warm: #fbbf24;   /* amber-400 */
  --producer-color: #f87171;/* red-400 (soft, distinguishable from teal) */
  --household-color: #2dd4bf;/* teal-400 */
  --border: #334155;        /* slate-700 */
}
```

### Rationale

- **Teal/cyan**: Distinct from typical "corporate blue", good for colorblind accessibility
- **Slate backgrounds**: Softer than pure black, better for extended viewing
- **Soft red for producers**: Distinguishable from teal households
- **Amber accents**: For highlights and warnings (not primary)

# T10: Redesign Color Scheme

## Status: pending
**Priority**: HIGH
**Dependencies**: —

## Problem

Current color scheme uses `#e74c3c` (bright orange-red) as primary on `#1a1a2e` (dark blue-black). User feedback: "Orange over dark looks very weird."

## Current Palette

- Background: `#1a1a2e` (dark blue-black)
- Primary/Accent: `#e74c3c` (orange-red)
- Secondary: `#3498db` (bright blue)
- Success: `#2ecc71` (green)
- Text: `#eee` (light gray)
- Panels: `#16213e` (navy)

## Issues

1. Orange-red on dark is harsh and draws too much attention
2. Looks like an error/warning color, not a primary brand color
3. Lacks sophistication for an academic/research tool
4. Poor accessibility — red-green colorblind users can't distinguish producer/household nodes

## Proposed Alternatives

### Option A: Teal/Cyan (Cool Scientific)
- Primary: `#00d4aa` or `#2dd4bf` (teal)
- Secondary: `#60a5fa` (soft blue)
- Accent: `#f472b6` (pink) for highlights
- Background: `#0f172a` (slate-900)
- Panels: `#1e293b` (slate-800)
- Vibe: Modern, scientific, clean

### Option B: Deep Indigo/Gold (Sophisticated)
- Primary: `#818cf8` (indigo-400)
- Secondary: `#34d399` (emerald-400)
- Accent: `#fbbf24` (amber-400)
- Background: `#0f0f1a` (near-black)
- Panels: `#1a1a2e` (current bg)
- Vibe: Elegant, premium, academic

### Option C: Monochrome + Accent (Minimal)
- Primary: `#e2e8f0` (slate-200, near-white)
- Accent: `#38bdf8` (sky-400)
- Background: `#020617` (slate-950)
- Panels: `#0f172a` (slate-900)
- Vibe: Stark, focused, data-forward

## Recommendation

**Option A (Teal/Cyan)** for:
- Distinct from typical "corporate blue"
- Good for colorblind accessibility (teal vs blue is distinguishable)
- Matches "physics field theory" theme (energy, flow)
- Modern without being trendy

## Files to Modify

- `index.html` — CSS custom properties block
- `src/visualization.js` — node colors
- `src/plots.js` — chart colors

## Implementation

Use CSS custom properties for easy theming:

```css
:root {
  --bg-primary: #0f172a;
  --bg-panel: #1e293b;
  --text-primary: #e2e8f0;
  --text-secondary: #94a3b8;
  --accent-primary: #2dd4bf;
  --accent-secondary: #60a5fa;
  --accent-warm: #f472b6;
  --producer-color: #f87171;  /* soft red, distinguishable from teal */
  --household-color: #2dd4bf; /* teal */
}
```

## Problem

`getAdjacencyMatrix()` indexed by raw node IDs instead of contiguous indices. After node removal, the matrix had holes (empty rows/columns), giving wildly wrong spectral radius values.

## Example (Before Fix)

5-node star with IDs [0,1,2,3,4]:
- Matrix: 5×5 (correct)
- ρ ≈ 2.0 (actually correct for directed star)

After removing node 2, IDs [0,1,3,4]:
- Matrix: still 5×5 (because max ID is 4, but only 4 nodes)
- Row 2 is all zeros → extra eigenvalue 0
- But `A[3][4]` exists while `A[2][*]` is empty → asymmetric structure
- Power iteration converges to wrong eigenvector

## Root Cause

```javascript
// BEFORE (broken):
getAdjacencyMatrix() {
  const n = this.nodes.size;  // 4 after removal
  const A = Array(n).fill(null).map(() => Array(n).fill(0));  // 4×4
  for (const edge of this.edges.values()) {
    A[edge.source][edge.target] = 1;  // edge.source could be 4, out of bounds!
  }
}
```

## Solution Implemented

```javascript
// AFTER (fixed):
getAdjacencyMatrix() {
  const nodes = Array.from(this.nodes.values());
  const idToIndex = new Map();
  nodes.forEach((n, i) => idToIndex.set(n.id, i));
  
  const n = nodes.length;
  const A = Array(n).fill(null).map(() => Array(n).fill(0));
  
  for (const edge of this.edges.values()) {
    const i = idToIndex.get(edge.source);
    const j = idToIndex.get(edge.target);
    if (i !== undefined && j !== undefined) {
      A[i][j] = 1;
      A[j][i] = 1;  // undirected
    }
  }
  return { matrix: A, labels: nodes.map(n => n.label) };
}
```

Also rewrote `spectralRadius()` with proper power iteration on the correctly-indexed matrix.

## Additional Change

**Removed misleading "Stable/Unstable" indicator** — For unweighted graphs, connected networks always have ρ ≥ 1. The economic stability condition was being misapplied. Now just shows ρ(A) value with a tooltip explaining what it means.

# T8: Fix Spectral Radius Calculation

## Status: 🔄 IN PROGRESS
**Priority**: CRITICAL
**Started**: 2026-08-10
**Dependencies**: —

## Problem

`getAdjacencyMatrix()` indexes by raw node IDs instead of contiguous indices. After node removal, the matrix has holes (empty rows/columns), giving wildly wrong spectral radius values.

## Example

5-node star with IDs [0,1,2,3,4]:
- Matrix: 5×5 (correct)
- ρ ≈ 2.0 (actually correct for directed star, but we want undirected)

After removing node 2, IDs [0,1,3,4]:
- Matrix: still 5×5 (because `this.nodes.size` counts 4, but max ID is 4)
- Row 2 is all zeros → extra eigenvalue 0
- But `A[3][4]` exists while `A[2][*]` is empty → asymmetric structure
- Power iteration converges to wrong eigenvector

## Root Cause

```javascript
getAdjacencyMatrix() {
  const n = this.nodes.size;  // 4 after removal
  const A = Array(n).fill(null).map(() => Array(n).fill(0));  // 4×4
  for (const edge of this.edges.values()) {
    A[edge.source][edge.target] = 1;  // edge.source could be 4, out of bounds!
  }
}
```

Wait, actually `n = this.nodes.size` is 4, but `edge.source` could be 4. This would cause `A[4]` to be undefined → silent failure or wrong result.

## Proposed Fix

Map node IDs to contiguous indices:

```javascript
getAdjacencyMatrix() {
  const nodes = Array.from(this.nodes.values());
  const idToIndex = new Map();
  nodes.forEach((n, i) => idToIndex.set(n.id, i));
  
  const n = nodes.length;
  const A = Array(n).fill(null).map(() => Array(n).fill(0));
  
  for (const edge of this.edges.values()) {
    const i = idToIndex.get(edge.source);
    const j = idToIndex.get(edge.target);
    if (i !== undefined && j !== undefined) {
      A[i][j] = 1;
      A[j][i] = 1;  // undirected
    }
  }
  return A;
}
```

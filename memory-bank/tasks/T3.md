## Details
Build an interactive canvas/SVG visualization of the economic network:
- Drag-and-drop node editor (producers = filled circles, households = open circles)
- Edge creation by clicking node pairs (edge mode toggle)
- Real-time parameter display on nodes/edges
- Animated flow visualization (goods moving along edges)
- Color-coded nodes by type and state
- 5 pre-configured scenarios: star, chain, twoIslands, cycle, random

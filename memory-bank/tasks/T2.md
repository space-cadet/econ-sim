## Details
Implement the networked intertemporal optimization model from Anarkitty's notes:

- Planner's objective: max Σₜ βᵗ Σᵈ ωᵈ uᵈ(cᵈₜ)
- Constraints: node flow balance + goods accounting
- Stability: ρ(A) < 1 spectral radius check
- Solver: gradient descent on Lagrangian with adaptive learning rate

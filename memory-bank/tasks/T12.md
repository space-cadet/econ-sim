# T12: UX: Inline Plots + Simulation Feedback

## Status: pending
**Priority**: HIGH
**Dependencies**: T9, T11

## Problem

User feedback:
1. "When I press the simulation button the graph canvas just flashes"
2. "The plots are on a different tab so one has to switch tabs to see what happens"

## Issues

### 1. No Visual Feedback During Simulation

**Current**: Click "Run Simulation" → solver runs → canvas may flicker → status updates
**Problem**: User doesn't know if anything happened
**Fix**: 
- Add loading spinner or progress bar
- Show "Solving..." text in status bar
- Disable Run button during solve
- On complete: show brief "Complete" flash or sound

### 2. Plots on Separate Tab

**Current**: User changes β or T, clicks Run, must manually switch to Plots tab
**Problem**: Breaks the explore-test-learn loop
**Fix options**:

**Option A: Auto-switch to Plots tab after Run**
- Simplest implementation
- `document.getElementById('plots-tab-button').click()` after solve

**Option B: Mini plots inline below network**
- Add 2 small charts below the network viz
- Show consumption + welfare inline
- Full plots still available on Plots tab

**Option C: Side-by-side layout (desktop)**
- Network on left, plots on right
- No tabs needed
- Mobile: stack vertically

## Recommendation

**Option B** for desktop + **Option A** as fallback:
- Add a "Quick Results" panel below the network showing 2 key plots
- Auto-switch to Plots tab on first run
- This gives immediate feedback while preserving detailed view

## Proposed Layout

```
┌─────────────────────────────────────────┐
│  Network Viz (main)                      │
│  [D3 force graph]                        │
├─────────────────────────────────────────┤
│  Quick Results (collapsible)             │
│  ┌──────────────┐  ┌──────────────┐     │
│  │ Consumption  │  │ Welfare      │     │
│  │ (mini chart) │  │ (mini chart) │     │
│  └──────────────┘  └──────────────┘     │
├─────────────────────────────────────────┤
│  Status: Converged | Welfare: 12.34     │
└─────────────────────────────────────────┘
```

## Animation During Solve

User asked: "Is the network supposed to evolve in some way that can be visualised?"

Yes — during the Play animation, flows should animate along edges. But during the static "Run Simulation" solve, we should show:
- Iteration counter updating
- Welfare value converging
- Maybe a pulsing effect on nodes

## Files to Modify

- `index.html` — add Quick Results section
- `src/ui.js` — add auto-switch, loading states
- `src/visualization.js` — add solve animation effects
- `src/plots.js` — add mini-plot support

## Notes

The "flash" the user sees is likely the D3 visualization re-rendering when the simulation completes. With T9 fixed (proper update pattern), this should be reduced. But we should also add explicit visual feedback so the user knows the solve happened.

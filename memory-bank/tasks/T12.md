## Problem

User feedback:
1. "When I press the simulation button the graph canvas just flashes"
2. "The plots are on a different tab so one has to switch tabs to see what happens"

## Solution Implemented

### 1. Quick Results Panel (Inline Plots)

Added collapsible panel below network visualization:

```html
<div id="quick-results" class="quick-results">
  <h4>📊 Quick Results</h4>
  <div class="mini-plots">
    <div class="mini-plot-container">
      <h5>Consumption</h5>
      <canvas id="mini-consumption"></canvas>
    </div>
    <div class="mini-plot-container">
      <h5>Welfare</h5>
      <canvas id="mini-welfare"></canvas>
    </div>
  </div>
</div>
```

- Shows mini consumption + welfare charts on every Run
- No tab switch needed for immediate feedback
- Auto-hides when no simulation data available

### 2. Loading State

```javascript
runSimulation() {
  const btn = document.getElementById('run-sim');
  btn.textContent = '⏳ Solving...';
  btn.disabled = true;
  
  const statusEl = document.getElementById('convergence-status');
  statusEl.textContent = 'Running solver...';
  statusEl.style.color = '#fbbf24'; // amber
  
  // Run solver in setTimeout to allow UI update
  setTimeout(() => {
    // ... solve ...
    btn.textContent = '▶ Run Simulation';
    btn.disabled = false;
  }, 50);
}
```

### 3. Auto-Tab Switch

On first successful simulation run, auto-switches to Plots tab:

```javascript
if (!this.hasShownPlots) {
  this.hasShownPlots = true;
  setTimeout(() => {
    document.querySelector('[data-tab="plots-tab"]').click();
  }, 500);
}
```

### 4. Status Bar Updates

- Shows convergence status with color coding (green = converged, red = failed)
- Shows iteration count
- Shows welfare value
- Shows current time step during animation
